Level 2: Kekuatan Kata Sandi

💡 Konsep Edukasi: Brute Force & Entropi

Serangan Brute Force mencoba menebak kata sandi Anda dengan menguji jutaan kombinasi huruf dan angka setiap detik. Kekuatan kata sandi adalah satu tolok ukur terhadap kekuatan, kerumitan dan keamanan dari suatu kata sandi rahasia yang digunakan sebagai pengenal. Kekuatan suatu kata sandi bergantung pada kombinasi, kerumitan dan panjang dari kata sandi tersebut.

🔍 Tahap 1/4: Identifikasi Kata Sandi

admin123

🔍 Tahap 2/4: Analisis Konteks

Jika pengguna bernama Budi, lahir 1990 di Jakarta:

Jakarta1990

🔍 Tahap 3/4: Apakah Password dibawah ini aman?

vQ7!x#P9z

🛡️ Tahap 4/4: Buat Kata Sandi Kuat

Syarat: Minimal 8 karakter, ada huruf besar, huruf kecil, angka, dan simbol (!@#$%^&*).

🎉 Level 2 Selesai!

Level 3: SQL Injection (SQLi)

💡 Konsep Edukasi: Manipulasi Database

SQL Injection (SQLi) adalah jenis serangan siber yang menyisipkan perintah SQL berbahaya ke dalam input aplikasi web, memanipulasi query ke basis data (database). Serangan ini mengeksploitasi kerentanan input, memungkinkan peretas melihat, mengubah, menghapus, atau mengambil alih data sensitif tanpa otorisasi.

Peretas memasukkan logika matematika yang selalu benar (seperti 1=1) untuk mengelabui form login.

💻 Simulasi: Bypass Login

Query: SELECT * FROM users WHERE user='admin' AND pass='[INPUT]'

Level 4: Cross-Site Scripting (XSS)

💡 Konsep Edukasi: Skrip Klien Berbahaya

Cross-Site Scripting (XSS) adalah kerentanan keamanan web di mana peretas menyuntikkan skrip berbahaya (biasanya JavaScript) ke situs web tepercaya. Kode ini kemudian dieksekusi oleh browser pengguna, memungkinkan pencurian sesi (cookie), pengambilalihan akun, atau pengalihan ke situs palsu.

Simulasi: Injeksi Skrip

Coba masukkan tag HTML untuk menjalankan fungsi alert(1), gunakan payload: <script>alert(1)</script> .

Level 5: Kriptografi & Encoding

💡 Konsep Edukasi: Menyembunyikan Pesan

Kriptografi termasuk seni menyandikan pesan. Kriptografi adalah ilmu dan seni mengamankan informasi dengan mengubah data (plaintext) menjadi kode rahasia yang tidak dapat dipahami (ciphertext) menggunakan algoritma tertentu. Teknik ini memastikan kerahasiaan, integritas data, dan autentikasi, memungkinkan data dikirim atau disimpan dengan aman tanpa bisa diakses pihak tidak berwenang.

🗝️ Tahap 1/3: Sandi Klasik (Caesar Cipher)

Sandi Caesar digeser maju (+3 langkah ke kanan). Contohnya: D menjadi A.
